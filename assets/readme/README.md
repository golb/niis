# README artwork

`niis-promenade-watercolor.png` is an original image generated for Niis with
OpenAI image generation on 8 August 2026. No source image, named artist, logo,
or third-party product identity was used. The release gate pins its SHA-256
digest so replacing it requires an explicit review.

`niis-logo.svg` is the original Bay N mark. Its curved diagonal follows the
shape of the Bay of Angels, while the three nodes represent supervised agents
moving through a shared workflow.
