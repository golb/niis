# Reports and feedback

Niis is source-available proprietary software, not an open-source project.
The public license does not grant permission to modify, redistribute, or
publish modified versions of the code. A public hosting platform may permit a
native fork under its own mandatory terms, but that does not grant broader
rights under the Niis license. Do not submit code changes without prior
written permission from the copyright holder.

Reproducible bug reports and focused technical feedback are welcome. To verify
an unmodified checkout:

```bash
npm ci
npm run release:verify
```

Report security issues privately as described in [SECURITY.md](SECURITY.md).
