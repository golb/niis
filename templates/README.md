# Templates

This directory holds durable onboarding templates used as the human review baseline for generated artifacts.

- `project-profile.template.md` captures the expected sections for generated repository classification and task-source profiling.
- `workflow.template.md` captures the expected `workflow.md` structure: YAML front matter plus reviewable body sections.

The runtime generator may render artifacts directly, but these templates keep the intended review surface explicit and stable.
